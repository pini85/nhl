# Arcade tab — build plan

Spec: `docs/superpowers/specs/2026-10-30-arcade-design.md`.

1. **Data.** `opponentLinesInOurGames` query + cached `getOpponentLinesInOurGames`; `lib/stats/arcade.ts` builds teams, ratings, opponents, revenge order. Tests in `tests/stats/arcade.test.ts` (fixture + hand-built).
2. **Engine (pure).** `components/arcade/engine/`: `rng.ts`, `rink.ts` (rounded-rect boards, goal frames, collisions), `types.ts`, `sim.ts` (state, fixed step, possession, shots, passes, hits, goals, clock, OT, events for effects), `ai.ts` (carrier / support / defender / goalie). Tests in `tests/arcade/` : boards keep the puck in, a shot into an empty net scores, posts bounce, AI-vs-AI full game runs with no NaN and a sane score.
3. **Browser layer.** `render.ts` (offscreen rink + skate marks, camera, sprites, particles, text, HUD), `input.ts` (floating stick + gestures), `audio.ts` (Web Audio synth), `Game.tsx` (loop, pause, end).
4. **Menus.** `ArcadeView.tsx`: title screen, Revenge Tour list with AVENGED stamps, Exhibition list, line-up picker with rating cards, INSANE toggle, result card. Progress in localStorage.
5. **Wiring.** `app/arcade/page.tsx`, bottom-nav "Arcade" tab (7 tabs must fit 320 px), `/arcade` in the e2e smoke list.
6. **Verify.** lint, typecheck, unit tests, production build; phone-size screenshots of menus and a played game from a local copy fed with the test fixtures (no database in the sandbox).
7. Commit and push.
